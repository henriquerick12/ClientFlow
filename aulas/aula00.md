# ClientFlow — Fase 0: Preparação do Projeto

## Objetivo

Preparar um ambiente de desenvolvimento organizado e versionado para iniciar a construção do ClientFlow.

## O que foi realizado

Foi criado o projeto local do ClientFlow e configurado seu ambiente inicial de desenvolvimento.

Foram utilizados:

- Python;
- ambiente virtual `.venv`;
- Git;
- GitHub;
- VS Code;
- `.gitignore`.

## Ambiente Python

Foi criado um ambiente virtual utilizando `.venv`, permitindo isolar futuramente as dependências Python utilizadas pelo backend.

## Versionamento

O projeto foi inicializado como um repositório Git.

Foram praticados conceitos como:

- repositório;
- staging;
- commit;
- branch;
- histórico;
- repositório remoto;
- push.

A branch principal utilizada foi `main`.

## GitHub

O projeto local foi conectado a um repositório remoto no GitHub, permitindo manter seu histórico de desenvolvimento também remotamente.

## .gitignore

Foi criado um `.gitignore` para impedir o versionamento de arquivos que não devem fazer parte do repositório.

Entre eles:

- ambiente virtual;
- cache do Python;
- arquivos compilados;
- variáveis de ambiente.

## README

Também foi criado um README inicial apresentando o ClientFlow como um sistema de gerenciamento de informações de clientes para empresas.

## Conhecimentos praticados

- configuração de ambiente;
- ambiente virtual Python;
- Git;
- GitHub;
- versionamento;
- organização inicial de projeto;
- documentação básica.

## Resultado

Ao final da fase, o ClientFlow possuía um ambiente de desenvolvimento preparado, versionado e conectado ao GitHub, criando a base para as próximas etapas do projeto.
